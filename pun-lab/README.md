# 諧音研究所｜生成插畫版

[開啟遊戲](https://gord992001.github.io/pun-lab/)

25 題 AI 生成插畫謎題，包含 15 題高難題（答案 2～10 字）及 10 題經典題。

- 同音字 1A2B，忽略聲調，重複音節不重複計算。
- 每題答錯五次即揭曉答案；字數不符不計次。
- 提示、猜測紀錄、下一題、自訂圖片題庫與瀏覽器進度保存。
- 所有圖片已內嵌在 index.html，可下載後離線遊玩。

## 離線使用

下載 index.html，再用 Chrome 或 Edge 開啟即可，不需要額外安裝套件或下載圖片。

插畫使用內建 image_gen 工具製作；完整提示詞見 illustration-prompts.txt。
